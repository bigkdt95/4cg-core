# 🔍 Guia de Indexação X-Ray & Metadados ClippXio

Este documento define a estrutura obrigatória para que o sistema de busca do **ClippXio** localize os teus ficheiros instantaneamente e o mascote possa sugerir criações automáticas.

## 🏷️ Hierarquia de Etiquetas (Tags)

Para ganhar **ClippX Coins (CXC)**, todos os registos devem seguir este padrão de etiquetas:

### 1. Categorias Principais (Obrigatório)
- `#obra`: Registos de construção, arquitetura e progresso técnico.
- `#escola`: Conteúdo educativo, aulas e materiais de estudo.
- `#familia`: Momentos pessoais e eventos familiares.
- `#projeto`: Documentos e mídias de projetos específicos em curso.

### 2. Atributos de Metadados (Busca Rápida)
Deves incluir sempre:
- **Data**: No formato `AAAA-MM-DD` (ex: 2024-04-15).
- **Localização**: Cidade ou Setor (ex: "Setor A", "Lisboa").
- **Palavras-Chave**: Pelo menos 3 termos descritivos (ex: #fachada, #reunião, #prazos).

## 💰 Economia de Recompensas
O sistema monitoriza a qualidade da tua indexação:
- **Indexação Completa**: +50 CXC por ficheiro.
- **Ficheiro Sem Tags**: Alerta do Mascote (bloqueia o Studio Criativo).

## 🎞️ Integração com Studio Criativo
O Studio utiliza estas tags para filtrar mídias:
- *Exemplo*: Ao selecionar o template "Evolução de Obra", o sistema busca automaticamente todos os ficheiros com a tag `#obra` e as organiza por data.
