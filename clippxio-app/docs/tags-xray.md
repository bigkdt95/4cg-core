# 📖 Dicionário de Tags & Metadados X-Ray

Este dicionário define os termos oficiais que o sistema de busca do ClippXio utiliza para indexar e localizar ficheiros instantaneamente no ecossistema G4C Core.

## 🏗️ Tags de Localização (Onde)
- `#setor-a`: Área externa / Fachadas.
- `#setor-b`: Interiores / Acabamentos.
- `#escritorio`: Documentação e planeamento.
- `#nuvem`: Ficheiros partilhados externamente.

## 📅 Tags de Temporalidade (Quando)
- `#diario`: Registos quotidianos.
- `#entrega`: Marcos de finalização de etapas.
- `#reuniao`: Registo de decisões e atas.
- `#urgente`: Pendências que precisam de atenção imediata.

## 🛠️ Tags de Processo (O quê)
- `#inspecao`: Verificação de qualidade.
- `#pagamento`: Comprovativos e notas fiscais.
- `#referencia`: Imagens de inspiração ou modelos.
- `#concluido`: Arquivos finais aprovados.

## 💡 Regras de Ouro para Metadados
1. Nunca use espaços nas tags (use hífens: `#foto-obra`).
2. Use sempre pelo menos 3 tags por ficheiro para maximizar o ganho de **ClippX Coins**.
3. O sistema X-Ray diferencia maiúsculas de minúsculas; use sempre minúsculas.
